# Daily_Tasks_Mobile_App_Cordova
. Vous pourriez installé Cordova pour voir l'app  
. Sinon aussi vous pourriez exécuter le fichier index.html sur votre navigateur pour voir  
. Si possible pour l'option navigateur, dans options de développement, sélectionnez 'vue adaptative' pour voir l'application sous format mobile  
. Après avoir ajouté une ou des tâches, vous pourriez sélectionner la tâche ajoutée, puis glissez dessus à droite ou à gauche pour y voir d'autres fonctionnalités  
. Si vous souhaitez supprimer toutes les tâches ajoutées, vous pourriez cliquer sur le bouton Réintialiser
